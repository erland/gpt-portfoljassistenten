# Kända begränsningar – Portföljassistenten v1

- V1 är inriktad på fondutbud som kan verifieras som tillgängligt för Swedbank ISK. Andra banker är arkitekturellt möjliga men saknar ännu provideradapter och verifierade flöden.
- Exakt look-through beror på aktuell och tillräckligt detaljerad fonddata. Saknad, gammal eller motstridig allokering kan därför begränsa analysen till intervall eller kvalitativa slutsatser.
- Swedbanks månadsvisa investeringsstrategi tolkas som taktisk marknadssyn. Projektets ±3/±5 procentenheter är egna deterministiska översättningsregler och inte publicerade exakta Swedbank-vikter.
- Strategiska regionvikter är avsiktligt inte hårdkodade; en aktuell bred global marknadsviktad referens behövs för exakta regionmål.
- Historisk avkastning används som jämförelseunderlag men inte som ensam ranking- eller prognosregel.
- Otydliga fondnamn/andelsklasser måste verifieras innan fondspecifika slutsatser kan göras.
- V1 är analys- och beslutsstöd och ersätter inte reglerad personlig investeringsrådgivning.
